# PixelPro

PixelPro is an AI-assisted product image automation platform for e-commerce teams and marketplace sellers.

## Product goal
Upload one or many raw product photos and turn them into consistent, marketplace-ready assets: background cleanup, centering, padding, resize, enhancement, shadow, export presets, and batch ZIP download.

This repository uses a monorepo architecture with a Next.js frontend and FastAPI image-processing backend.
